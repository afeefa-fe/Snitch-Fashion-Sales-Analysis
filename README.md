# Snitch-Fashion-Sales-Analysis
 
 Project Description

This project focuses on analyzing Snitch Fashion sales data using Python to understand sales performance, product performance, customer segments, and profitability. The project follows a complete data analysis process, starting from data cleaning and preparation to data visualization and business insights.

The dataset was cleaned using Python, Pandas, and NumPy by handling missing values, removing duplicate records, correcting data inconsistencies, cleaning text fields, converting date values, and handling invalid numerical values.

After cleaning the data, Matplotlib and Seaborn were used to create different visualizations to identify patterns and trends in the sales data. The analysis includes sales by product category, top-performing products, monthly sales trends, customer segment analysis, price and sales relationships, sales distribution, profit distribution, and category-segment comparisons.
